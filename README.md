# SongHub for Android: downloads

This repository only hosts the **SongHub** Android app (`SongHub.apk`) for phones, tablets and Android TV.

- **Latest version:** https://github.com/macalix-mcfright/songhub-releases/releases/latest/download/SongHub.apk
- **Find a song number:** https://songhubsearch.netlify.app

**Android TV:** install the free **Downloader** app, then enter the SongHub web address followed by `/SongHub.apk`
(for example `songhubsearch.netlify.app/SongHub.apk`).

Each release lists its version and the file's SHA-256 so you can check the download.
